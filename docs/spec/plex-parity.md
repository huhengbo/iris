# 界面照搬 Plex：差异清单与分批计划

2026-10-24 与用户逐项确认，原则见 ADR 0026。每项格式为「现状 → Plex → 改成」。标【未核实】的 Plex 细节来自搜索摘要或已有认知，官方原文没有抓到，用户也无法登录 Plex 核对。审阅时可以直接改「改成」一栏。

现状里的代码位置都在 `client/lib/` 下。

## ① 导航、首页、稍后观看

### 手机导航（宽度 < 840）
- 现状：底栏「首页 / 资料库 / 搜索 / 我的」（`app/shell.dart:18`）。「我的」是列表页：设置、播放列表、我的收藏、我的设备、服务器、管理后台、关于、切换用户、退出登录（`features/me/me_page.dart:64-122`）。
- Plex：底栏是 Home、Library、Live TV、On Demand、Discover；首页顶部有搜索、投屏、Watchlist 和头像，头像菜单里是个人资料、下载、应用设置、切换用户。
- 改成（有意偏离 Plex）：保留四栏。「我的」改成 Plex 头像菜单的样式：顶部头像加用户名，下面依次是设置、播放列表、我的收藏、我的设备、服务器、切换用户、退出登录。管理后台并入「设置」（见 ⑤），关于移进设置。首页右上角加「稍后观看」图标。

### 宽屏和 Web 导航（宽度 ≥ 840）
- 现状：左侧 4 项 `NavigationRail`（`app/shell.dart:96`），要进资料库得先进列表页。
- Plex Web：左侧栏是首页，然后服务器名和它下面的各资料库；管理员在每个库的 `⋯` 里能扫描和刷新【未核实：菜单项名称和顺序】。顶栏有搜索、Activity（状态）、设置和账户。
- 改成：
  - 左侧栏依次是首页、稍后观看、服务器名，服务器名下直接列出各资料库。
  - 管理员在资料库 `⋯` 里有：同步此资料库、刷新元数据、编辑资料库、管理推荐、删除。
  - 顶栏左边是搜索框；右边依次是活动图标（仅管理员，下拉显示正在播放和运行中的任务，点进去是「状态 › 仪表盘」）、设置扳手、头像菜单（同手机「我的」）。
  - 侧栏不再有「资料库列表」「搜索」「我的」三项。

### 首页
- 现状：精选轮播 → 继续观看 / 最近播放 → 我的收藏 → 每库「最近添加的〈库名〉」（`features/home/home_page.dart:113-273`）。服务器的 hubs 配置支持 featured、recent、favorites、latest 四种。
- Plex：没有大轮播，顶部固定是 Continue Watching；其余推荐行由各资料库的 Manage Recommendations 决定，资料库要固定到侧栏才会出现在首页。
- 改成：
  - 顺序为继续观看 → 稍后观看 → 各库推荐行。
  - 推荐行的种类和顺序在每个资料库的「管理推荐」里设置（见 ②）。
  - 收藏行默认关闭，可以在设置里打开。
  - 去掉精选轮播，`DESIGN.md` 的首页描述要改写。
  - 「3 秒内看到继续观看」这条契约不变。

### 稍后观看（新功能）
- 定义见 `CONTEXT.md`：用户想看、还没看的电影或整部剧集，只能放可见资料库里的条目。电影看完、剧集全部集都看完时自动移出。
- 入口：
  - 详情页按钮（书签图标）、海报卡菜单；
  - 首页一行；
  - 手机首页右上角图标；
  - 宽屏侧栏一项；
  - TV 侧栏一项。
- 列表页：海报网格按加入时间倒序，支持移出，空状态给出说明。
- 后端：新表和接口，Emby 兼容接口不暴露这份列表。【待定：Emby 有没有对应概念，实施时查证】

## ② 资料库页

### 页面结构
- 现状：海报墙上方一行筛选胶囊，依次是排序、类型、年份、观看状态、收藏，管理员另有「问题」；合集在右上角图标里；只有网格视图（`features/library/library_page.dart:110-460`）。
- Plex：顶部标签「推荐 / 资料库 / 合集 / 播放列表 / 分类」，默认进「推荐」。「资料库」标签上方有筛选和排序控件【未核实：视图切换、海报尺寸、A-Z 跳转条】。
- 改成：
  - 标签只做「推荐 / 资料库 / 合集 / 分类」，默认进「推荐」。播放列表属于用户，仍放在「我的」。
  - 推荐：本库继续观看、最近添加、最近上映、评分最高和若干类型行，由「管理推荐」开关、排序。
  - 资料库：工具栏改成 Plex 式下拉。第一个下拉是筛选（类型、年份、观看状态、收藏、稍后观看；管理员另有「问题」），第二个是排序和升降序，右侧是网格 / 列表视图切换。按名称排序时右侧出现 A-Z 跳转条。
  - 合集：现有的合集页面搬进这个标签。
  - 分类：类型卡片墙，点进去是筛选好的「资料库」标签。

### 编辑资料库（管理员）
- 现状：「编辑」对话框（`features/admin/library_dialog.dart`）和「高级设置与统计」页（`features/admin/library_advanced_page.dart`）分开；首页推荐行也放在高级页里。
- Plex：Manage Library 下有「编辑」（分页对话框）和 Manage Recommendations【未核实：对话框分页名称】。
- 改成：
  - 资料库 `⋯ → 编辑资料库` 是分页对话框：
    - 通用：名称、类型、语言；
    - 添加文件夹：资料库目录；
    - 高级：资料库行为开关，以及元数据下载器、图片获取器、字幕下载器三块有序列表（Emby 做法，ADR 0025），字幕下载语言。
  - 资料库 `⋯ → 管理推荐` 单独一页：列出这个库所有推荐行，每行有两个开关「在首页显示」「在推荐标签显示」，可拖动排序。
  - 统计移到「状态 › 仪表盘」。

## ③ 详情页、海报卡、更多类似

### 详情页按钮
- 现状：播放 · 已看 · 收藏 · 加入播放列表 · `⋯`（仅管理员）（`features/detail/detail_header.dart:228`、`features/detail/detail_page.dart:413`）。版本、画面、音频、字幕各占一行，点开是选择弹层（`features/detail/stream_rows.dart:24`）。
- Plex：播放 · 已看切换 · Watchlist · 编辑 · `⋯`。Audio / Subtitle 是详情页上的下拉【未核实：按钮顺序、编辑是不是铅笔图标】。
- 改成：
  - 按钮依次是播放（琥珀色）· 已看 ✓ · 稍后观看 · 编辑铅笔（仅管理员）· `⋯`（所有人可用）。
  - 按钮行下方是版本、音频、字幕三个下拉，画面信息并到版本下拉的说明里。
  - `⋯` 里普通用户有：收藏、加入播放列表、获取信息。管理员另有：修正匹配、取消匹配、刷新元数据、重新读取文件、编辑字幕、同步此目录、加入合集、删除。

### 管理菜单改名
- 现状菜单见 `features/admin/item_actions.dart:153-190`，季菜单见 `features/detail/detail_season_bar.dart:142`，单集菜单见 `features/detail/detail_episodes.dart:226`。
- 改成：只改和 Plex 意思相同的项。
  - 「重新匹配」改叫「修正匹配」（Fix Match）。
  - 编辑、取消匹配、刷新元数据、获取信息、删除本来就和 Plex 对得上，不改。
  - 「重新读取文件」是到 115 重新列目录，和 Plex 的 Analyze 意思不同，不改名。
  - 「删除并清理 115」改叫「删除」，确认对话框里再说明会清理 115。
  - 菜单顺序按上面详情页 `⋯` 的顺序排。

### 海报卡
- 现状：只有管理员能长按，或点右上角 `⋯`；普通用户只能点进详情（`features/library/poster_card.dart:52,215`）。
- Plex：桌面悬停时出现操作层，中央是播放键，底部是已看切换、编辑和 `⋯`【未核实：具体图标】。
- 改成：
  - 桌面悬停出现这层操作；手机长按出同一个菜单；TV 不加悬停层，菜单在详情页。
  - 所有人都能用，菜单项按角色过滤，项目同详情页 `⋯`，另外加上播放、已看和稍后观看。

### 更多类似
- 现状：没有。
- 改成：详情页底部一行，从可见资料库里取类型重合度高的条目。不做影评。附加内容仍然忽略。

### 搜索、人物页
- 搜索已经按「影片和剧集 / 人物 / 单集」分组，和 Plex 按类型分组一致，不改。宽屏的搜索入口移到顶栏的搜索框。
- 人物页不改。

## ④ 内置播放器

- 现状：底栏依次是播放、±10 秒、倍速、字幕和音轨、画面，各是独立按钮。手势有双击快进快退、长按 2 倍速、横滑调进度（`features/play/player_page.dart`）。字幕面板里有「搜索更多…」。
- Plex：中央是后退 10 秒、播放、前进 30 秒；顶栏是关闭、片名、投屏；设置面板里有音频、字幕、字幕大小、速度【未核实：移动端具体布局】。
- 改成：
  - 中央大按钮：后退 10 秒 / 播放 / 前进 30 秒。
  - 顶栏：关闭、片名（剧集加季集）、投屏。
  - 右上角齿轮打开一个面板，分音频、字幕、播放速度、画面几项。「搜索更多…」改叫「搜索字幕」。
  - 手势全部保留（ADR 0010）；双击跳转的秒数和按钮一致，后退 10 秒、前进 30 秒。

## ⑤ 设置与管理后台

- 现状：
  - 用户设置在「我的 › 设置」。
  - 管理后台入口在「我的 › 管理后台」，结构是概况加「媒体 / 用户 / 服务 / 维护」四组共 20 页（`features/admin/admin_page.dart:231-312`）。
  - 「设置」页按插件网络代理、资料库、服务器分段（`features/admin/settings_page.dart`）。
- Plex：一个设置页，左栏分组。账户和应用设置是每个用户都有的；服务器名下面的设置、管理、状态、排障只有管理员能看到【未核实：完整分组名称和顺序】。
- 改成：合成一个「设置」。宽屏由顶栏扳手进入，手机由「我的 › 设置」进入。

```
账户
  个人资料与密码 / 设备与会话
本机
  常规 / 播放器 / 字幕与音轨 / 关于
── 服务器「光圈」（仅管理员）──
设置
  常规（服务器名）/ 远程访问（对外访问地址）
  资料库（最小体积、失效保留天数）/ 网络（插件网络代理）
  计划任务 / Webhook
管理
  资料库 / 资源来源 / 用户 / 插件
  待处理 / 条目 / 回收站
  故障排查（日志、系统健康、备份与恢复）
状态
  仪表盘（正在播放、资料库统计、待处理事项）/ 警报 / 同步 / 后台任务 / 播放历史
```

- 「配置向导」只在没配置完时出现在最上面，保持现状。
- 原「概况」并入「状态 › 仪表盘」。
- 路由按新结构改。旧的 `/admin/...` 地址重定向到新地址，同仓客户端一起改。

## ⑥ TV

- 现状：左侧窄栏「首页 / 资料库 / 搜索 / 我的」（`features/tv/tv_shell.dart:16`）。首页顶部是焦点条目的大背景，下面的行是精选推荐 / 继续观看 / 最近添加（`features/tv/tv_home_page.dart:133-189`）。
- Plex 大屏端：2026 年改回可折叠左侧栏，收藏的资料库直接成为顶层项。
- 改成：
  - 侧栏依次是搜索、首页、稍后观看、各资料库，底部是设置和切换用户。焦点进入侧栏时展开显示文字，离开时收成图标。
  - 首页保留随焦点变化的大背景，行与手机一致：继续观看 → 稍后观看 → 各库推荐行，去掉「精选推荐」。默认焦点改成第一行第一张卡。
  - TV 不提供管理和插件配置。

## 分批与验证

按 ① → ⑥ 的顺序实施，每批单独提交。每批要做：

- 同步改写 `DESIGN.md` 对应段落；
- 跑 `dart format`、`dart analyze` 和相关 `flutter test`；改了后端的再跑后端测试；
- 用浏览器（Web）检查主要流程，以及加载、空数据、错误几种状态；
- 涉及 TV 的批次额外检查方向键焦点顺序。

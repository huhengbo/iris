# 0015 公网域名 + HTTPS 访问；播放令牌固定 24 小时有效

- 状态：已接受
- 日期：2026-10-01

## 背景

本机播放器要直接访问本服务的播放跳转地址；家人朋友不在同一个局域网里。

## 决策

- **访问方式**：公网域名，通过 HTTPS 反向代理暴露服务。证书和反代（Caddy、Nginx、Cloudflare Tunnel 等）由部署者自己准备，本服务只监听 HTTP。
- 管理后台配置**对外访问地址**（例如 `https://movie.example.com`），所有发给播放器的地址都基于它生成，不使用请求的 Host 推断。没有配置时签发返回 409，客户端提示请管理员配置（M6 起在「系统设置 → 服务器」里填写，只接受 http/https 地址）。
- **播放令牌**：
  - 有效期**固定 24 小时**，不提供配置项；
  - 绑定用户、可播放条目和版本（外挂字幕绑定字幕文件）；
  - 只能访问播放跳转，不能访问其他接口（例外：第三方客户端用客户端设备的令牌访问串流地址，见 ADR 0024）；
  - 签发前校验可见范围（ADR 0009）。
- **立即失效**：用户被禁用、修改或重置密码、失去对应资料库的权限时，已签发的令牌立即失效。实现方式是每次跳转时重新校验用户状态和可见范围，而不只是校验签名。
- 播放跳转对每个令牌做基础限流，避免地址泄露后被滥用，也避免对 115 请求过多：每分钟最多 120 次跳转（拖动进度时播放器会重新请求，留足余量），每小时最多 30 次向 115 取链（缓存命中不计）；超出返回 429 和 `Retry-After`。

## 影响

- 在 Infuse 等播放器中，超过 24 小时从它们自己的历史记录重播会失败，需要回到本应用重新点播放。这是已知且接受的行为。

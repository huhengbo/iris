# 0027 115 可写入，多端同时播放用副本取链，风控熔断按接口分组

- 状态：已接受
- 日期：2026-10-26
- 修订：ADR 0006（取消「只读」原则）、ADR 0007（熔断范围）
- 部分由 ADR 0028 修订：熔断状态和生活事件游标改存 115 插件自己的数据目录
- 参考：[DDSRem-Dev/MoviePilot-Plugins](https://github.com/DDSRem-Dev/MoviePilot-Plugins) 的 p115strmhelper（GPLv3，只借鉴做法，不复制代码）

## 背景

- 115 的一个直链最多 3 个并发连接（ADR 0003 实测），两台设备同时播放同一个文件时，后来的设备容易拿到 403。p115strmhelper 的「多端播放」把文件复制一份，用副本的 pickcode 取一个独立的直链，几秒后删掉副本。这要写 115，和 ADR 0006 的只读原则冲突。
- ADR 0007 的风控熔断一触发就暂停所有 115 请求。p115strmhelper 在网页版接口返回 405 时改用 App 版接口重试，说明 115 的拦截是按接口分开的；同步撞上风控时，播放取直链没有理由跟着停 30 分钟以上。
- 生活事件游标只记事件 ID。p115strmhelper 同时记 ID 和时间，比上次处理到的还早的事件不再处理。

## 决策

- **115 可写入**：取消 ADR 0006 的「只读」原则，功能需要时可以复制、删除、建目录等。现有写入：导出目录树的临时文件（ADR 0007）、打开「最近记录」（M8）、删除外挂字幕（ADR 0025）、多端同时播放的副本。扫描本身仍然不改 115。
- **多端同时播放**：115 插件「设置」页的开关，默认关闭。
  - 直链缓存按（pickcode，UA，播放会话）区分。播放会话是播放令牌或 Emby 会话；WebDAV 按用户算一个会话。同一个播放令牌重新请求跳转时命中自己的缓存。
  - 某个文件已有别的会话拿着有效直链时，新会话复制这个文件到「光圈临时目录/多端播放」，按修改时间找出副本，用副本取直链，5 秒后删除副本（进 115 回收站）。副本取链返回「文件上传不完整」时，依次等 0.5、1、2 秒重试。
  - 同一时间只复制一份。目录里出现认不出的残留时全部删掉，这一次退回原文件；复制失败（风控、空间不足等）也退回原文件的直链，不让播放失败。
  - 设置页写明限制：最多适合两个 IP 同时播放，频繁复制可能触发风控，滥用可能导致账号被封。
- **熔断按接口分组**：分「网页版接口」（webapi 等：列目录、导出、复制、删除、登录、账号）和「App 版接口」（proapi：取直链、App 版生活事件）两组，各有一个熔断，退避规则不变；全局限速仍然共用每秒 2 次。
  - 同步只走网页版接口，被拦时不改走 App 版：改走的话同步流量会把播放那组也拖进风控。
  - 网页版沿用原来的熔断设置项，升级前已有的熔断状态继续有效。
  - 115 插件账号页分别显示哪组受限、何时恢复；后台汇总、配置向导和健康检查里的 115 状态格式不变，`rate_limited` 表示至少一组受限。
- **生活事件双游标**：游标记处理到的最新事件 ID 和时间。拉取时 ID 不大于游标 ID，或时间早于游标时间（同一秒仍算新）的事件就停止。升级前保存的状态没有时间，第一次拉取后补上。
- 生活事件里发生在本应用专用目录（导出目录、多端播放目录）的变动直接忽略。

## 取舍

- 多端播放按播放会话而不是 UA 区分：两台同型号设备 UA 相同，按 UA 区分时它们仍然共用一个直链。代价是同一台设备重新点播放会拿到新令牌，也会复制一次。
- 副本删除后，已经交出去的直链是否还能继续用，p115strmhelper 的代码和测试里都没有验证，本应用也还没有用真实账号实测，见「待验证」。
- 熔断分组会让「被拦」的影响面变小，但也意味着网页版受限期间，管理员手动操作（列目录、登录）仍然失败。

## 后续计划（本期不做）

- **接入 115 开放平台作为第二通道**：OAuth 登录（access_token、refresh_token，刷新加锁并持久化），取直链用 `/open/ufile/downurl`，列目录每页最多 1150 条；429 按 `X-RateLimit-Reset` 精确等待，「已达到当前访问上限」固定等待约 70 秒。Cookie 通道被风控时播放可以切到开放平台。需要申请 AppID，并在 115 插件里加一套 OAuth 登录。
- 整目录移动时直接改数据库里的路径前缀，不再列目录（p115strmhelper `helper/life/client.py`）。
- 字幕和独立音轨按文件名关联（p115strmhelper `helper/transfer/linked_subtitle_audio.py`）。

## 待验证

- 副本删除后，用副本取到的直链是否仍可播放、拖动；如果不行，改为直链过期后再删副本。
- 115 的风控是否确实按接口分组；如果两组同时被拦，行为退化为原来的全局熔断。

# ADR 0020：第三期管理能力的统一入口

## 状态

已采用（2026-10-03）。

## 决策

管理员操作从片库、详情、季和单集的「⋯」菜单进入；后台保留服务器级设置、任务和排障页面。服务端所有第三期接口继续使用现有 Bearer 会话和管理员依赖，普通用户对管理员筛选和管理对象按 403 或 404 处理。

第三期新增对象使用独立迁移和 SQLite 表：通用元数据锁定按 `entity_kind/entity_id/field` 保存；合集、播放列表、警报、计划任务、Webhook、资料库设置和设备会话各自保存生命周期，避免把管理状态塞进影视条目表。长操作创建 `background_task` 记录，重复请求通过幂等键或对象主键收敛。

115 直链不会被服务端转码或代理。回收站只清理本地数据库和图片引用；外部播放器、投屏和 WebDAV 不提供伪造的“终止播放”按钮。

## 结果

- 基线迁移（`0001_baseline.sql`）已包含第三期对象和设备字段。
- 管理 API 按领域放在 `backend/app/api/admin/`，客户端后台入口位于“活动与维护”。
- 片库问题筛选只对管理员开放，资料库可见性沿用现有 `visible_library_ids`。

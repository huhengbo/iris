# 0005 播放方式由用户选择；在线播放按「原画 → 115 转码」自动降级

- 状态：**已废弃**，被 ADR 0010 取代（Web 端没有在线播放；App 用 mpv 内核直接播放原画，不需要 115 转码降级）。其中「本机播放器调起方式」和「短期令牌」两条仍然有效，已合并进 ADR 0010。
- 日期：2026-10-01

## 背景

- 片源以 MKV 为主。iPhone Safari 不支持 MKV；其他浏览器对 HEVC、DTS/TrueHD、PGS 字幕的支持也不完整。
- 115 账号是 VIP，可以使用 115 自带的在线转码（多清晰度 m3u8）。
- 用户能接受在线播放时画质、音轨、字幕不如原画。

## 决策

每次播放都由用户在两种**播放方式**中选择；用户可以设置默认方式，播放时仍然可以临时切换。

1. **在线播放**：在页面内播放，有续播、倍速、长按加速、滑动调整进度。
   - 按「原画 → 转码」的顺序选择片源：
     - 预判浏览器能解码原文件（根据容器、编码和 `canPlayType`）时，走 ADR 0003 的 302 原画直链。
     - 预判不能，或者原画播放出错时，自动切到 115 转码 HLS（用 hls.js 播放，iOS 用原生 HLS）。
     - 用户可以手动切换清晰度，也可以切回原画。
   - 转码流还没准备好或者获取失败时，提示改用本机播放器。
   - 不自建 ffmpeg 转码。
2. **本机播放器**：调起设备上的播放器播放原画直链，没有进度上报，只记录「开始播放」。
   - iOS 通过 URL Scheme 调起（如 Infuse、VLC、nPlayer、SenPlayer），Android 通过 `intent://` 调起系统选择器。另外提供「复制播放地址」。
   - 播放地址带一个短期令牌，绑定用户和文件，不依赖 Cookie。

## 待验证

- 115 转码 m3u8 的获取接口、清晰度参数、分片地址是否需要改写或代理、分片是否绑定 UA 或 Cookie。
- 新上传的文件多久转码完成，以及没有转码时接口返回什么。
- 转码流保留哪些音轨和字幕。

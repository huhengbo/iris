# 0012 多版本、附加内容与字幕

- 状态：已接受（本机播放器的调起格式和外挂字幕参数已按调研实现，真机实测待做）
- 日期：2026-10-01

## 背景

资料库中存在同一部片的多个版本，字幕既有外挂文件，也有内封字幕轨。

## 决策

### 多版本
- 一个**可播放条目**（电影或单集）可以关联多个**版本**，每个版本对应一个云端视频文件。
- 识别时，同一资料库内匹配到同一个 TMDB 条目（剧集还要求季和集相同）的文件，归为同一条目下的不同版本。不同目录的作品匹配到同一个 TMDB 条目时也合并（ADR 0016）。
- 版本的显示名从文件名解析，包括分辨率、来源（REMUX、BluRay、WEB-DL 等）、HDR/DV、编码和体积，例如「2160p · REMUX · HDR · 58GB」。
- 默认播放上次用过且仍可用的版本，没有时用体积最大的（近似画质最高），用户可以手动切换。
- 播放进度记在可播放条目上，不记在版本上，所以换版本也能续播。
- 管理员可以在待处理或详情页中把版本拆分出去或改挂到其他条目。拆出和改挂的结果同步不会改动（ADR 0016）。

### 附加内容
- MVP 忽略附加内容，不进影视墙。判断规则：
  - 目录名命中 `Extras`、`Featurettes`、`Sample`、`Trailers`、`Behind The Scenes` 等（不区分大小写）；
  - 文件名包含 `sample`、`trailer` 等关键字；
  - 体积小于阈值（可配置，默认 200MB；阈值只作用于电影资料库，避免误伤短剧集；修改后下次同步时生效）；
  - 蓝光原盘目录里每张盘只保留最大的文件。
- 被忽略的文件记录原因，列在待处理的「已忽略」里，管理员可以手动指定恢复（ADR 0016）。

### 字幕
- **外挂字幕**：同步时把同一目录下的字幕文件（`.srt`、`.ass`、`.ssa`、`.vtt`、`.sup`、`.sub`、`.idx`、`.smi`）关联到对应版本。
  - 关联规则：字幕文件名以视频文件名（去掉扩展名）开头，后缀用来解析语言和标记，例如 `.chs`、`.zh-CN`、`.eng`、`.forced`。
  - 只保存引用，播放时同样通过播放跳转获取。
- **内封字幕**：由播放器自己读取，本系统不解析。内置播放器读到的字幕轨会上报给服务端，用于详情页显示（ADR 0019）。
- App 内置播放器（mpv）可以同时加载外挂字幕和内封字幕，并支持切换。
- Web 调起本机播放器时，如果该播放器的 URL Scheme 支持字幕参数，就一并传入；不支持时只能用内封字幕。各播放器的支持情况待验证。

### 调起链接（M6，2026-10-01）

服务端在签发播放链接时拼好各播放器的调起链接（`launch`），客户端只按平台挑选，以后修正格式只改服务端。`{url}` 是播放跳转地址，`{sub}` 是默认外挂字幕的跳转地址，二者都做 URL 编码。

| 播放器 | 链接 | 外挂字幕 |
| --- | --- | --- |
| Infuse | `infuse://x-callback-url/play?url={url}&sub={sub}` | 传 |
| VLC | `vlc-x-callback://x-callback-url/stream?url={url}&sub={sub}` | 传 |
| nPlayer | `nplayer-` 加上未编码的原地址 | 没有参数 |
| SenPlayer | `senplayer://x-callback-url/play?url={url}` | 没有找到参数 |
| Android | `intent://{host}{path}#Intent;scheme={对外地址的协议};type=video/*;S.title={标题};end` | 不传，由系统选择器列出能打开视频的应用 |

- 默认外挂字幕：版本标为默认的字幕优先，其次是完整（非强制）的中文字幕。
- 所有外挂字幕的跳转地址都随签发结果返回，「复制播放链接」时可以逐个复制，给不支持字幕参数的播放器手动加载。
- 这些格式来自各播放器的公开说明和社区用法，没有一手实测。**待做**：在 iPhone 上逐个验证能否调起、是否带上字幕，在 Android 上验证系统选择器；结果记回本节，必要时调整服务端格式。
- Web 在当前页打开调起链接（新窗口会被 Safari 拦截）。请求签发是异步的，Safari 是否允许在异步之后跳转自定义协议也要一起实测；不允许时改成先签发、再让用户点一次打开。

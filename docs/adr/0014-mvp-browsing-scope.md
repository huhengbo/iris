# 0014 第一期影视墙的页面与功能范围

- 状态：已接受
- 日期：2026-10-01

## 第一期做

- **首页**：
  - 「最近播放」：Web 端按开始播放的时间排序；App 端上线后显示带进度的继续观看。
  - 每个资料库一行「最近添加」，再加各资料库的入口。
- **资料库页**：海报墙。
  - 排序：添加时间、上映日期、评分、名称。
  - 筛选：类型、年份、已看或未看。
- **详情页**：
  - 背景图、海报、标题、原名、年份、TMDB 评分、时长、类型、简介。
  - 演员和导演：名字和头像，头像缓存到本地。
  - 版本选择、播放按钮、标记已看或未看。
- **剧集**：
  - 季列表；
  - 每季的集列表：剧照、集名、简介、已看标记；
  - 「下一集」推荐。
- **搜索**：只查本地数据库，匹配中文名、原名和英文名。
- **演员页**（2026-10-01 补充，原列在「不做」里）：
  - 详情页点演员或导演进入。
  - 显示头像、姓名、出生日期、出生地和简介。简介等资料第一次打开时从 TMDB 拉取（`zh-CN` 回退到 `en-US`）并缓存，没配 TMDB 或请求失败时只显示姓名和头像。
  - 列出这个人在本地资料库中参演或执导的作品（按可见范围过滤），带角色名，按年份倒序。不显示 TMDB 上有、本地没有的作品。

## 实施顺序（2026-10-01）

- M5 完成了首页（精选、各资料库最近添加、资料库入口）、海报墙的排序和类型、年份筛选、详情、季和集、演员页、搜索。
- 依赖播放记录的部分放到 M6 和播放一起做：首页「最近播放」、海报墙的「已看 / 未看」筛选、详情页和集列表的已看标记，已在 M6 完成。
- 首页「最近播放」每部作品一条（剧集显示最近播放到的那一集），最多 16 条，排在精选之后、各资料库最近添加之前。
- 版本显示名由服务端拼好（含大小），客户端直接显示，不再自己拼。

## 第一期不做

收藏、合集、用户评分和评论、推荐与相似影片、多语言界面、家长控制和分级。

## 为以后预留

- 演员和导演的信息（TMDB person ID、姓名、头像、角色名）随条目入库。每部作品保留前 20 位演员（剧集用全部季的演员表），这样演员页列出的本地作品才比较完整；详情页只展示前几位。

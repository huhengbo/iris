# 0006 对 115 只读扫描，按资料库目录识别

- 状态：部分被取代（2026-10-26，ADR 0027 取消「只读」原则；扫描本身仍不改 115）
- 日期：2026-10-01

## 背景

用户的 115 目录已经比较规范，例如 `电影/片名 (年份)/xxx.mkv`、`剧集/剧名 (年份)/Season 01/S01E01.mkv`。

## 决策

- 本应用对 115 **只读**：不重命名、不移动、不删除、不上传。MVP 不做「整理」。
  - 例外一：导出目录树时会在专用目录生成一个临时导出文件，用完立即删除（ADR 0007）。
  - 例外二（M8）：开启 115 生活事件监听时，调用一次 `life_calendar_setoption` 打开账号的「最近记录」。这会改账号设置，所以默认关闭，只在管理员手动开启时调用。
- 管理员仿照 Emby 创建**资料库**（名称、类型、一个或多个 115 资料库目录），详见 ADR 0011。
- 识别：参考 MoviePilot 的文件名和目录名解析规则，得到片名、年份、季集，再匹配刮削源条目。
- 识别失败或匹配不确定的文件进入**待处理**列表，由管理员手动指定刮削源条目。手动指定的结果优先于自动识别，重新扫描时不会被覆盖。
- 不缓存视频内容；元数据持久化保存，见 ADR 0001。

## 影响

- 不会弄乱用户的网盘，也不需要处理「整理」失败后的回滚。
- 目录不规范的文件识别率会下降，靠「待处理」列表人工兜底。

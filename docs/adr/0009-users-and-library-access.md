# 0009 账号由管理员创建，按用户分配可见的资料库

- 状态：已接受
- 日期：2026-10-01

## 背景

使用者是本人、家人和朋友，不对外开放。

## 决策

- 角色只有两种：**管理员**、**普通用户**。
- **不开放注册**，账号只由管理员创建。管理员可以禁用账号、重置密码、修改角色；普通用户只能修改自己的密码。
- 首个管理员在初始化时由部署配置生成。
- **可见范围**按资料库分配，与 Emby 一致：
  - 普通用户只能访问被分配的资料库；新建用户时默认分配全部资料库。
  - 管理员的可见范围和普通用户一样配置（2026-11-03 起，见文末补充）。
  - 新建资料库时，不自动分配给已有的普通用户。
- 可见范围由服务端强制校验，覆盖影视墙、搜索、详情、继续观看，以及播放令牌的签发和每次播放跳转时的校验。不能只在前端隐藏。
- 播放进度、继续观看、已看标记都按用户隔离。
- 管理功能只对管理员开放：115 账号、资料库、同步、待处理、TMDB 配置、用户管理。

## 影响

- 需要维护「用户 ↔ 资料库」的关联，所有媒体查询都要带上这个过滤条件。

## 实施补充（M5，2026-10-01）

- 范围外的资料库、条目、季、人物和搜索结果一律按不存在处理，返回 404，不用 403 暴露「有但看不到」。
- 人物只要在可见范围内有一部作品就能打开，作品列表只列可见的条目；不可见时先返回 404，不会去 TMDB 拉资料。
- 管理员通过 `PUT /api/admin/users/{id}/libraries` 整体替换某个用户的可见范围。修改后递增该用户的 `token_version`，旧的登录立即失效，需要重新登录才能看到新范围。

## 实施补充（管理首页，2026-10-03）

- 用户多了一个可选的「全部资料库」开关，对应 Emby 的「启用所有媒体库访问」。打开后能访问全部资料库，包括以后新建的；关掉后按勾选的资料库分配。默认关闭，上面「新建资料库时不自动分配」的规则对没打开开关的用户不变。
- 新建用户时可以直接指定可见的资料库或打开这个开关；不指定时仍分配当时的全部资料库。
- 开关和资料库一起通过 `PUT /api/admin/users/{id}/libraries` 修改，任何一项变化都递增 `token_version`。
- 用户记录最近活动时间 `last_seen_at`，在登录和刷新令牌时更新，精度约为访问令牌的有效期（15 分钟），只用于管理后台展示。

## 实施补充（管理员可见范围，2026-11-03）

- 管理员不再无条件看到全部资料库，和普通用户一样由「全部资料库」开关和分配的资料库决定；服务端 `visible_library_ids` 不再区分角色。
- 管理功能（资料库、条目、同步、待处理等后台接口）仍只看角色，不受可见范围限制，所以可见范围再小的管理员也能管理全部资料库。
- 迁移 `0006` 给已有管理员打开「全部资料库」，升级后行为不变；初始化生成的首个管理员同样默认打开。新建的管理员和普通用户一样，默认分配当时的全部资料库。

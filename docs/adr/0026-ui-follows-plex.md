# 0026 界面结构和交互照搬 Plex，Emby 只补 Plex 没有的部分

- 状态：已接受
- 日期：2026-10-24
- 补充：ADR 0011、ADR 0025
- 部分取代：播放器控件改为照搬网易爆米花，见 ADR 0032

## 背景

用户端、管理端和 TV 端的界面一直是自己设计，局部参考 Emby（资料库概念、插件设置、下载器列表、编辑字幕）。用户要求对照 Plex 逐页检查，并照搬 Plex。

## 决策

- **照搬两层**：信息架构（导航、页面划分、菜单位置）和交互流程（首页推荐行、详情页按钮和 `⋯` 菜单、资料库标签与工具栏、播放器控件、设置结构）以 Plex 为准。视觉皮肤（色板、字体、圆角、动效）继续用 `DESIGN.md` 的「影院暗场」。
- **分端对标**：手机对标 Plex 新版移动 App，平板、桌面和 Web 对标 Plex Web，TV 对标 Plex 大屏端（2026 年改回的可折叠左侧栏）。
- **冲突时以 Plex 为准，Emby 补缺口**：Plex 没有对应形态的能力保留 ADR 0025 的 Emby 做法，放进 Plex 风格的页面里。具体包括：资料库三个下载器有序列表、管理员的「编辑字幕」对话框、插件自带设置页、115 账号放在插件设置。收藏也保留，Emby 兼容接口要用。
- **Plex 有、Iris 没有的只补「稍后观看」**：发现、流媒体聚合、直播电视、好友分享和 Plex Pass 入口都不做，也不留占位入口。
- **有意偏离 Plex 的地方**：手机保留「首页 / 资料库 / 搜索 / 我的」四栏；手机和 Web 都保留完整的管理功能（Plex 的服务器设置基本只在 Web 上）；内置播放器保留 ADR 0010 要求的长按加速、横滑调进度。

## 取舍

- 照搬一个成熟产品的结构，以后少争论；代价是这一轮要改动几乎所有页面，原来的「活动与维护」后台入口也要重组。
- Plex 官方帮助站点抓不到原文，Plex 的细节（菜单项顺序、设置页名称）只根据搜索摘要和已有认知确定，用户也无法登录 Plex 核对。差异清单里标注了未核实的项，以本 ADR 的原则和清单为准，不再逐项追求与 Plex 一致。

## 结果

- 差异清单和分批计划见 `docs/spec/plex-parity.md`。
- 首页去掉精选轮播，`DESIGN.md` 对应的布局描述随各批实施改写。
- 新术语「稍后观看」「推荐行」「更多类似」见 `CONTEXT.md`。

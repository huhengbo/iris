# 0025 插件交互照搬 Emby：设置收进插件，资料库按顺序启用下载器，在线字幕存服务端

- 状态：已接受
- 日期：2026-10-24
- 补充：ADR 0012、ADR 0013、ADR 0021、ADR 0022
- 部分由 ADR 0028 修订：备份改为主库加插件数据的打包；插件密钥和配置改存插件自己的数据目录

## 背景

插件 SDK 已经能按能力注册 provider，但插件本身的维护分散在别处：TMDB 的 Key 和代理在「设置」页，115 的登录在「115 账号」页，挂载目录在「资源」页，插件页只能启停。资料库只能选一个元数据插件，也没有在线字幕：字幕只认 115 或本地来源上与视频放在一起的文件，而资源来源都没有写入能力。

用户要求插件的交互和展现直接对标 Emby（必要处参考 Plex）。

## 决策

- **配置由插件自带的设置页维护**：密钥、服务地址、参数都在「插件 › 某插件」的设置页里，沿用 ADR 0021 的 iframe/WebView 页面，不做宿主原生的声明式表单。TV 端不提供插件配置。
- **TMDB 和 115 改成真正的插件**：TMDB 的 Key、代理迁进插件自己的密钥和配置，改走宿主 HTTP；115 的登录、账号、设备收进 115 插件的设置页，挂载目录仍在「资源」页。旧的 `PUT /admin/settings/tmdb`、`/admin/cloud115/*` 和对应页面直接移除，升级时迁移数据。
- **插件网络代理**：「设置」里有一个全局插件代理，插件可以选择沿用、不走代理或自定义。
- **资料库按顺序启用下载器**：元数据下载器、图片获取器、字幕下载器三个有序列表，按资料库配置。
  - 元数据：排第一的负责匹配；后面的只按外部 ID（IMDb、TMDB）查，补前面缺的字段和图片；没有可对应的外部 ID 就跳过，不按片名搜索。评分按来源分别保存，不受补缺限制。（2026-10-24 补充：主下载器拿别的语言顶上的简介、标语和标题也算缺，补缺记录的外部 ID 核对一致才采用。）
  - 图片：每类图片取自排在最前、有这类图的获取器；同一获取器内按资料库元数据语言、无文字、英文的顺序挑。（2026-10-24 补充：只有其他语言的图也算有，排在最后；背景图改为无文字优先。）
  - 字幕：按顺序问，第一个返回结果的下载器里取得分最高的一条，每种语言一份。
- **在线字幕存服务端**：字幕下载器取回的字幕压缩后存进服务端数据库（2026-10-24 修订：原写「数据目录」；备份只备份 SQLite 单文件，存库后备份、恢复自动包含且与数据库一致），绑定到版本，所有能看到该版本的用户都可以选用；不写回 115 或本地来源。WebDAV 也列出在线字幕。版本被拆出、忽略或文件变为未归入时，它的在线字幕随之删除；重新匹配不影响。
- **字幕入口两处都做**：管理员在条目「⋯ → 编辑字幕」里查看、删除、搜索下载（Emby 式）；普通用户在播放器和详情页的字幕选择里「搜索更多…」（Plex 式），由用户权限「允许下载在线字幕」控制，默认开启。删除外挂字幕会删除来源上的文件（115 进回收站），本地来源不支持删除。
- **自动下载**：计划任务「下载字幕」按资料库的下载语言执行；某语言已有外挂字幕、在线字幕或上报过的内封字幕，或音轨就是该语言（可选）时跳过。

## 取舍

- 插件自带页面要求每个插件写前端，换来的是 115 扫码这类交互不必由宿主逐个实现；为降低成本，宿主扩充插件页公共组件。
- 补缺只认外部 ID：国产或冷门作品经常补不上，但不会把别的作品的简介填进来。
- 在线字幕不写回来源：服务端多了一份需要备份的数据，换来不依赖 115 上传和本地目录权限。
- 旧接口不保留兼容期：客户端与服务端同仓发布，只有自家客户端在用。

## 结果

- 「服务 → 115 账号」菜单和「设置」页的 TMDB 区块消失，插件页成为维护插件的唯一入口。
- 新增插件：射手网 assrt（字幕）、豆瓣（元数据补缺，解析网页，可选 Cookie）、Fanart.tv（图片）。暂不接 OpenSubtitles，因此「要求哈希匹配」选项暂不提供。
- 插件配置完全依赖插件页之后，Android WebView 需要真机验证。
- 第三方插件运行时和 Emby 式「插件目录」仍然推后。

## 实施记录

- 2026-10-24 P1：插件中心按分类分组的卡片、详情页「设置 / 网络 / 关于」；全局插件代理和插件代理模式（基线迁移）；设置页公共组件 `SettingsEndpoint` / `IrisPlugin.settingsForm`。
- 2026-10-24 P2：TMDB Key 存为 `builtin.tmdb` 的密钥 `api_key`，代理改用插件有效代理，设置页带测试连接和连接状态；旧 `PUT /admin/settings/tmdb` 和设置页 TMDB 区块已移除。旧代理由启动迁移转成插件自定义代理，旧 Key 在启动时重新加密迁移。**与决策的偏差**：TMDB 请求仍由自己的 HTTP 网关发出，没有改走宿主 HTTP——宿主 HTTP 每插件 0.5 秒间隔，而刮削需要 0.1 秒的优先级限速和 429 重试；代理解析与宿主 HTTP 共用 `PluginHost.effective_proxy`。
- 2026-10-24 P3：115 账号（状态、扫码登录、Cookie、退出）进入 `source.115` 的「账号」页；`/admin/cloud115/*` 和「服务 → 115 账号」已移除，凭据存储不变；资料库选目录改用通用的 `GET /admin/resources/{id}/browse`（暂不显示目录已被哪个资料库占用）。
- 2026-10-24 P4：`subtitle` 表统一登记外挂和在线字幕（`source`，基线迁移），在线字幕内容 zlib 压缩存 `online_subtitle`，按版本+内容 sha256 去重，每版本最多 20 条；编码统一转 UTF-8，格式按内容识别（srt/ass/ssa/vtt）。播放、详情、Emby、WebDAV 都列出在线字幕。用户权限「允许下载在线字幕」（基线迁移，默认开，管理员不受限）。内置字幕下载器「射手网 assrt」（API Token 在插件设置页；官方文档未能访问核实，按第三方实现兼容新旧返回格式）。用户搜索和下载有限流（对管理员同样生效）。顺带修复：资料库默认字幕语言取错、中文偏好 zh-CN/zh-TW 与字幕 zh-Hans/zh-Hant 不匹配、外挂字幕全部失效时版本从详情消失。
- 2026-10-24 P5：资料库三个有序列表存 `library_plugin`（基线迁移，旧的单个元数据插件已搬入），由 `GET/PUT /admin/libraries/{id}/downloaders` 维护，客户端在资料库高级设置里勾选、排序。新增 SDK 能力 `image.fetch` 和 `MetadataRecord.external_ids` / `fallback_fields`；条目外部 ID、按来源的评分、每类图片的提供方见基线迁移。同步新增「补充元数据和图片」阶段，只处理新匹配的条目，已有条目在「刷新元数据」时才重新补缺选图；补缺插件请求时暂时不可用，本次同步不再请求它，条目留到下次同步再补。内置插件：TMDB 增加取图和外部 ID；豆瓣（只补缺，按 IMDb 找到条目后核对页面上的 IMDb，可选 Cookie）；Fanart.tv（取图，剧集只认 TVDB ID，Key 只放请求头）。计划任务「下载字幕」（基线迁移）默认启用、语言为空时不做事；没有结果 7 天、失败 1 天内不重试同一版本同一语言，每次最多搜索 300 次；手动搜索字幕也按资料库字幕下载器列表过滤。豆瓣页面结构和 Fanart.tv 接口只用样本测试，未用真实网络核实。

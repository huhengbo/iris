# 0011 仿照 Emby 建立资料库，资料库目录来自 115

- 状态：已接受
- 日期：2026-10-01

## 背景

用户希望和 Emby 一样，可以自己建立资料库，区别只在于资料库的目录选自 115。

## 决策

- 管理员创建、编辑、删除**资料库**。每个资料库包含：
  - 名称；
  - 类型：电影或剧集。MVP 不支持 Emby 的「混合内容」等其他类型；
  - 一个或多个**资料库目录**：通过 115 目录选择器添加，保存目录 ID，展示时带上路径；
  - 排序权重：决定首页各分区的显示顺序。
- 同一个 115 目录（及其子目录）只能属于一个资料库，添加时校验目录之间是否重叠。
- 首页按资料库分区展示，例如「电影」「4K 电影」「国产剧」「美剧」各占一个分区；每个资料库有自己的影视墙页面。
- **影视条目按资料库划分**，与 Emby 一致：同一部 TMDB 影片如果出现在两个资料库里，就是两个独立的影视条目。版本合并只发生在同一个资料库内（见 ADR 0012）。
- 同步可以按资料库触发；可见范围按资料库分配（ADR 0009）。
- 删除资料库时，删除它的条目和版本记录，图片缓存随后清理；不影响 115 中的文件。删除前需要二次确认。

## 影响

- 播放进度记在可播放条目上，所以同一部片在两个资料库里各有一份进度。

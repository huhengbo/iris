# 0032 内置播放器的控制层改为照搬网易爆米花

- 状态：已接受
- 日期：2026-11-04
- 补充：ADR 0026（播放器控件这一项不再以 Plex 为准）、ADR 0010

## 背景

ADR 0026 让播放器控件照搬 Plex：中央三个大按钮，音轨、字幕、速度、画面都收在齿轮里。用户对照网易爆米花的播放页，要求整页改成它的布局。爆米花是国内用户熟悉的 NAS / 网盘播放器，常用操作都直接摆在画面上，不用进齿轮。

## 决策

- **布局照搬爆米花**：顶部返回 + 片名，右边投屏和齿轮；左侧竖排旋转屏幕、画面比例，右侧锁屏；底部两端时间（写到时，「00:03:34」）夹着进度条，再下一行左边倍速「1.0x」，正中上一集 / 后退 10 秒 / 播放暂停 / 前进 10 秒 / 下一集，右边音轨、字幕、选集。缓冲时画面正中转圈并写百分比。
- **快进快退对称**：按钮、双击和遥控器左右键都是 10 秒（原来是后退 10 / 前进 30）。
- **底栏按钮只开一段**：倍速、音轨、字幕各自打开播放设置面板里对应的一段；齿轮仍打开完整的四段面板。
- **剧集才有上一集 / 下一集 / 选集**：客户端用已有的作品详情和季接口找到这一集的位置，跨季时取相邻一季；特别篇不夹在正片中间。播放列表连播和电影不显示这三个按钮。
- **锁屏**：锁住后控制层只剩锁，画面手势和返回键都不起作用，点画面只呼出锁。
- **电视**：没有旋转、画面比例和锁屏（画面比例在齿轮里）；焦点从播放键往上是进度条，再往上是顶栏。
- 视觉皮肤仍用「影院暗场」：琥珀进度条、遥控器聚焦的琥珀底；按钮平时只有白色图标，不加圆底。

## 取舍

- 和 Plex 的其他页面不再是同一套语言，但播放器是独立的全屏页面，不影响导航和其他页面的一致性。
- 爆米花没有公开手势和布局的说明，这里依据用户提供的截图；截图看不到的细节（选集面板、倍速档位）沿用现有面板。
